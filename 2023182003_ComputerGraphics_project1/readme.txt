5개의 점을 찍어 경로 설정 후 게임 시작
먼저 바구니에 100개의 도형을 넣는 사람이 승리

방향키 -> 파란 바구니 이동
a, d-> 노란 바구니 이동
파란 바구니에 닿았던 도형은 왼쪽상단에 있는 바구니 창으로 이동
노란 바구니에 닿았던 도형은 오른쪽상단에 있는 바구니 창으로 이동

도형: 시간에 따라 도형 생성되고 설정된 경로를 따라 이동 한 도형 여러번 자를 수 있음, 초기 3~8각형까지 랜덤 생성, 랜덤으로 회전하거나 회전하지 않고 이동, 교점 기준으로 도형이 슬라이스

도형이 바구니에 닿으면 cmd창에 각각 바구니에 들어있는 도형 개수 출력

게임 엔드 - 바구니에 도형이 100개 들어가서 게임이 끝나면 각각 바구니에 있는 도형 확인 가능, cmd창에 우승자와 각각 들어있는 도형 개수 출력, s키 눌러서 경로 설정 후 다시 시작 가능

키보드 명령
s:	재시작, 다시 5개의 점을 찍어 경로 설정 후 게임 시작
n:	파란 바구니 창 다음 도형 출력하기
m:	노란 바구니 창 다음 도형 출력하기
r:	경로 출력
l:	도형 출력 모드 설정 (FILL / LINE)
+:	speed up
-:	speed down (처음은 최소 속도로 설정)
q:	프로그램 종료
a:	노란 바구니 왼쪽으로
d:	노란 바구니 오른쪽으로
->:	파란 바구니 오른쪽으로
<-:	파란 바구니 왼쪽으로

마우스 명령
시작 전 -> 5개의 점으로 경로 지정 (경로를 지정해야 게임이 시작됨)
게임 중 -> 마우스 드래그로 도형 자르기
게임 끝 -> 없음

추가 구형한 내용: 바구니 두개로 더 많이 도형을 얻은 사람이 우승, 한 도형을 여러번 슬리이스, 도형을 회전시키며 움직임, 5개의 점으로 경로 출력, 프로그램 재시작
